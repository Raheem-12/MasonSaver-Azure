# MasonSaver

A cloud-deployed textbook price comparison application that helps students find lower-priced textbooks.

## Technologies

- React
- Java
- Spring Boot
- PostgreSQL
- Azure Static Web Apps
- Azure App Service
- Azure Database for PostgreSQL
- Azure Key Vault
- GitHub Actions

## Features

- Search textbooks
- Compare prices
- Display lowest-priced new and used copies
- REST API
- Cloud-hosted database

## Azure Architecture

React (Static Web Apps)
        ↓
Spring Boot (App Service)
        ↓
Azure PostgreSQL
